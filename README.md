# umaumafancount-mp4tocsv

ゲーム画面の録画（MP4）から、OCR（文字認識）を用いて「キャラクター名」と「ファン人数」を抽出し、メンバーごとの集計結果を JSON 形式で出力するツールです。

GUI モード（マウス操作）と、バッチモード（コマンドライン操作）の両方に対応しています。

## 📥 ツールの入手方法 (ダウンロード)

プログラムの実行環境（Pythonなど）を自分で用意するのが難しい方は、以下の手順で「完成済みパッケージ」をダウンロードしてください。

1. **GitHubのリポジトリページ**を開きます。
2. 画面右側にある **[Releases]** という項目をクリックします。
3. 一番上にある **[Latest]** と書かれた最新バージョンのタイトルをクリックします。
4. ページ下部の **[Assets]** という項目の中に、`release_package.zip` というファイルがあるので、それをクリックしてダウンロードします。
5. ダウンロードした `release_package.zip` を解凍して、中にあるファイルを使用してください。

---

## 🚀 主な特徴
* **GUI モード (推奨)**: マウス操作で直感的に動画選択やメンバー設定が可能。
* **バッチモード (CLI)**: 大量の動画をコマンドラインから一括処理可能。
* **高度な誤認識対策**: GUI 上で「文字の読み間違い（例: ザ $\rightarrow$ サ）」を簡単に修正・登録可能。
* **自動集計**: 複数フレームを解析し、最も頻出する数値を統計的に算出するため、精度が高い。

## 🛠 インストール・環境 (開発者向け)

ソースコードから直接利用する場合は、以下の環境を準備してください。

### システム要件
* **OS**: Windows 11 (WinRT OCR を使用するため Windows 専用です)
* **Python**: Python 3.13 (推奨)
* **モニター**: FullHD 以上の解像度を推奨

### セットアップ手順
1. **Python のインストール**
   - Microsoft Store から「Python 3.12」または「3.13」をインストールしてください。
2. **リポジトリの取得と環境構築**
   ```bash
   # Gitを利用する場合
   git clone <このリポジトリのURL>
   cd umaumafancount-mp4tocsv
   
   # パッケージのインストール
   pip install uv
   uv sync
   ```

## 📖 利用手順

### 1. GUI モードでの使用方法 (初心者の方におすすめ)

マウス操作で簡単に解析が行えます。

1. **アプリの起動**
   - **パッケージ版の方**: 解凍したフォルダ内の `main.py` を実行（環境に合わせて `python main.py` 等）
   - **開発版の方**: `uv run main.py` を実行
2. **動画の選択**
   - アプリが起動したら「動画を選択」ボタン（またはファイル選択ダイアログ）から、解析したい MP4 ファイルを選択します。
3. **メンバー管理 (必要に応じて)**
   - 認識精度を上げたい場合は、「**メンバー管理**」ボタンから、誤認識しやすいパターンを登録できます。
4. **解析の実行**
   - 動画を選択すると自動的に解析が開始されます。進捗はウィンドウ内のステータスパネルにリアルタイム表示されます。
5. **結果の確認**
   - 完了すると、画面下部のリストに解析結果が表示されます。
   - 結果は `output/output.json` に保存されます。

### 2. メンバー管理 (GUI による精度向上)

OCR の誤認識（例：「ザ」を「サ」と読んでしまう等）を簡単に修正できます。

1. GUI の「**メンバー管理**」ボタンをクリック。
2. 左側のリストからメンバーを選択。
3. **名前の修正**: 「名前」フィールドを直接編集し、「✓ 変更を適用」をクリック。
4. **パターンの追加**: 誤認識される文字列（例：「ザ波雲明」）を「置換パターン」に入力し、「+ 追加」をクリック。
5. 「保存して閉じる」をクリックすると、設定が保存されます。

### 3. バッチモードでの使用方法 (大量処理・自動化向け)

コマンドラインから直接動画を指定して実行できます。

```bash
# 単一動画の解析
uv run main.py <動画ファイル名.mp4>

# デバッグモード (中間画像を保存)
uv run main.py <動画ファイル名.mp4> --debug

# グレースケール変換を利用 (精度向上用)
uv run main.py <動画ファイル名.mp4> --img-scale gray
```

## 📁 ディレクトリ構造
* `input/`: 解析に使用する動画ファイル、およびメンバー設定ファイル (`memberList.txt`, `memberReplace.json`) を格納。
* `output/`: 解析結果 (`output.json`) が出力されます。
* `output/debug/`: `--debug` オプション使用時、OCR の中間結果（切り抜き画像等）が保存されます。

## ⚠️ 注意事項
* **解像度について**: FullHD 解像度での動作を前提としています。4K 等の高解像度では動作が保証されません。
* **動画の撮り方**:
  * スクリーンショット（動画）内にマウスカーソルが映り込まないよう注意してください。
  * スクロールが速すぎると、フレームのタイミングによって数字が正しく読み取れない場合があります。
* **免責事項**: 本ツールは外部ツールです。本ツールによるアカウント停止等につきましては一切の責任を負いかねます。
